# SQL 探索模板说明（文件1/2/3/4/6）

本目录用于给 SQL 探索工具提供对照基线，帮助快速定位以下两个关键字段：

- `接口时间`
- `责任人`

并校验责任人是否可与姓名角色表匹配。

- `待处理文件1_模板.xlsx`
- `待处理文件2_模板.xlsx`
- `待处理文件3_模板.xlsx`
- `待处理文件4_模板.xlsx`
- `待处理文件6_模板.xlsx`
- `template_spec.json`（模板规范，供程序读取）

## 样例设计原则

- 脱敏：不放真实项目敏感数据。
- 覆盖边界值：
  - 空责任人
  - 多责任人（逗号、顿号、分号、斜杠）
  - 无效姓名（不在姓名角色表）
  - 跨年日期
  - 版次差异（A/B/C）
  - 作废/已完成/待完成混合状态

## 如何用于 SQL 探索

1. 先运行 `sql_explorer.exe` 导出候选列报告。
2. 使用本目录模板中的语义基线（时间/责任人/完成/科室）比对报告推荐列。
3. 若候选结果与模板基线不一致，优先检查：
   - 表结构命名差异（字段名不直观）
   - 责任人列是否为 ID 需关联人员表
   - 时间字段是否为计划时间而非实际完成时间

## 备注

- 模板用于“字段语义对照”，不是完整生产数据格式的替代。
- 若后续新增文件类型或规则变更，请同步更新 `template_spec.json`。
