## 1. 核心模块

### 1.1 base.py - 主程序控制器

**行数**: 7,131 行
**职责**: 应用程序入口、GUI 初始化、流程控制、事件处理

**核心功能**:

- 窗口创建与布局管理
- 配置加载与保存（config.json）
- 角色权限验证与过滤
- 处理流程调度（刷新→处理→导出）
- 定时任务管理（自动处理）
- 系统托盘与开机自启动
- Registry 钩子集成
- 缓存复用快路径（文件未变化时跳过重复处理）
- Registry 增量写入（仅文件变更时触发）
- 崩溃日志记录

**关键函数**:

| 函数 | 功能 |
|------|------|

| `_run_auto_flow` | 自动模式处理流程 |

| `optimized_read_excel` | 优化的 Excel 读取 |
| `concurrent_read_excel_files` | 并发读取 Excel 文件 |

### 1.2 core/main.py - 数据处理核心

**行数**: 4,029 行
**职责**: 文件识别、数据筛选、结果导出

**核心功能**:

- 6 种文件类型的正则识别
- 多步筛选逻辑（科室→日期→完成状态→排除条件）
- 责任人提取（中文字符/分隔符处理）
- 保持原始 Excel 格式的导出
- Registry 状态查询与待审查任务加回
- 版次筛选（同一接口保留最高版次）
- 指派记忆应用

**6 种文件的筛选逻辑**:

| 文件类型 | Process1(科室/类别) | Process2(日期) | Process3(条件) | Process4(排除/条件) |
|---------|---------------|---------------|-------------------|---------------|
| 1 | H列含 25C1/2/3 | K列日期范围 | M列空且A列非空 | B列含"作废" |
| 2 | I列含"河北分公司-建筑结构所"或 25C1/2/3 | M列日期范围 | N列空且A列非空 | 排除：AB列以 4444 开头且 F列=传递（仅非 1907/2016） |
| 3 | I列为"B"且 AL列以"河北分公司-建筑结构所"开头 | 组1：M列日期范围; 组2：L列日期范围 | 组1：T列空; 组2：Q列空 | 最终=组1∪组2 |
| 4 | AF列以"河北分公司-建筑结构所"开头 | P列为"B"或 P列为空且 AC列为"B" | S列日期范围 | V列为空 |
| 5 | G列含 25C1/2/3 | L列日期范围 | N列为空 | - |
| 6 | V列含"河北分公司.建筑结构所" | I列非空且日期≤14天（管理员跳过日期） | M列="尚未回复/超期未回复" | - |

**版次筛选规则**:

| 文件类型 | 版次列 | 规则 |
|---------|--------|------|
| 1 | - | 无版次筛选 |
| 2 | E列 | A < B < C < …，仅保留最高版次 |
| 3 | AC列 | A < B < C < …，仅保留最高版次 |
| 4 | I列 | A < B < C < …，仅保留最高版次 |
| 5 | - | 无版次筛选 |
| 6 | AC列 | A < B < C < …，仅保留最高版次 |

## 2. UI 模块

### 2.1 ui/window.py - 窗口管理器

**行数**: 2,005 行
**职责**: GUI 组件创建、数据显示、用户交互、界面显示控制

**核心功能**:

- 主窗口布局与自适应
- 6 个选项卡的 Treeview 显示
- 滚动条支持（垂直+水平）
- 勾选框状态管理（从 Registry 读取）
- 列宽智能计算
- 元数据存储（用于点击事件）
- 版本号显示（右下角）
- 数据库状态显示（左下角，集成 db_status.py）

**重要说明**: 界面显示由 `window.py` 的 `WindowManager.create_widgets()` 方法控制，`base.py` 不应重复创建 UI 组件。

**勾选框逻辑**:

- 状态从 Registry 的 `confirmed_at` 字段读取
- 上级角色点击 → 确认/取消确认任务
- 设计人员点击 → 显示提示（无权限）
- 点击后 100ms 延迟刷新显示

**列宽算法**:

- 中文字符: 16px
- 英文字符: 8px
- 范围限制: 60-300px
- 1.2 倍富余系数
