## 1. 项目概述

**接口筛选程序**是一个企业级 Excel 数据自动化处理工具，服务于建筑设计院的接口管理工作流程。

### 核心功能

- 7 种接口类型批量识别与筛选
- 多项目并行处理（基于项目号自动分组）
- 角色权限管理（基于姓名角色表）
- 任务状态跟踪（Registry 模块）
- 写入任务队列化（write_tasks 模块）
- 指派记忆功能（自动沿用上次指派人）
- 自动化定时处理
- 结果导出（精简业务列）
- 自动更新机制（双进程热更新）
- 系统托盘与开机自启动
- 数据库状态实时显示
- 帮助文档查看器

## 5. 六种文件类型

| 类型 | 名称 | 文件名正则 | 科室列 | 时间列 | 完成列 | 责任人列 |
|------|------|-----------|--------|--------|--------|---------|
| 1 | 内部需打开接口 | `(\d{4})按项目导出IDI手册.*` | H列(7) | K列(10) | M列(12) | R列(17) |
| 2 | 内部需回复接口 | `内部接口信息单报表(\d{4}).*` | I列(8) | M列(12) | N列(13) | AM列(38) |
| 3 | 外部需打开接口 | `外部接口ICM报表(\d{4}).*` | L列(11) | Q列(16) | T列(19) | AP列(41) |
| 4 | 外部需回复接口 | `外部接口单报表(\d{4}).*` | I列(8) | M列(12) | V列(21) | AH列(33) |
| 5 | 三维提资接口 | `三维设计提资接口单报表(\d{4}).*` | K列(10) | O列(14) | R列(17) | K列(10) |
| 6 | 收发文函 | `收发文清单(\d{4})?.*` | W列(22)主办室 | I列(8) | J列(9) | X列(23) |

## 6. 角色权限体系

| 角色 | 权限范围 | 时间窗口(显示+导出) | 特殊功能 |
|------|---------|-------------------|---------|
| 所领导 | 查看所有数据 | 2个工作日 | 忽略延期任务 |
| 一室主任 | 查看结构一室(25C1)数据 | 7个工作日 | 确认任务、指派、忽略延期 |
| 二室主任 | 查看结构二室(25C2)数据 | 7个工作日 | 确认任务、指派、忽略延期 |
| 建筑总图室主任 | 查看建筑总图室(25C3)数据 | 7个工作日 | 确认任务、指派、忽略延期 |
| 接口工程师 | 查看本室数据 | 无限制 | 确认任务、指派 |
| 设计人员 | 仅查看责任人为自己的数据 | 无限制 | 填写回文单号 |
| 管理员 | 查看所有数据 | 无限制 | 全部功能 |

**说明**: 时间窗口从 `config.json` 的 `role_export_days` 读取，显示和导出统一。延期任务始终保留。

## 7. 核心工作流

```
┌─────────────────┐
│  启动程序       │
│  检查更新       │
└────────┬────────┘
         ↓
┌─────────────────┐
│  加载配置       │
│  初始化界面     │
└────────┬────────┘
         ↓
┌─────────────────┐      ┌─────────────────┐
│  刷新文件列表   │ ───→ │  识别7种文件    │
│  (自动/手动)    │      │  提取项目号     │
└────────┬────────┘      └─────────────────┘
         ↓
┌─────────────────┐
│  开始处理       │
│  (多线程)       │
└────────┬────────┘
         ↓
┌─────────────────────────────────────────────────────────────┐
│ FOR 每种文件类型 & 每个项目号:                               │
│   1. 读取Excel / 加载缓存                                   │
│   2. 4步筛选逻辑 → 3. 生成DataFrame                         │
│   4. Registry 记录状态(增量) → 5. 应用角色过滤 + 时间窗口    │
└────────────────────────────────────────────────────────────┬┘
         ↓
┌─────────────────┐      ┌─────────────────┐
│  显示结果       │      │  过滤已确认任务  │
│  更新 GUI       │ ←─── │  过滤已忽略任务  │
└────────┬────────┘      └─────────────────┘
         ↓
┌─────────────────┐
│  导出结果       │
│  生成汇总报告   │
└─────────────────┘
```
