# 接口管理工具 - 使用说明

> **版本**: 以程序右下角显示为准
> **适用对象**: 设计人员、室主任、接口工程师、所领导、管理员
> **文档更新时间**: 2026-09-02

---

## 1. 通用功能

### 1.1 三分钟快速上手

首次使用时，按以下顺序即可完成一次完整操作：

1. 双击"接口筛选.exe"，选择自己的账户并输入密码
2. 设置接口Excel所在的 **文件夹路径**；需要导出时再设置 **导出结果位置**
3. 勾选需要查看的 **项目号** 和 **接口类型**
4. 依次点击 **刷新文件列表**、**开始处理**，等待处理完成
5. 根据自己的角色处理任务：
   - 设计人员：双击接口编号填写回文单号，也可多选后批量填写；FU任务可点击 **是否已完成** 方框或批量标记完成
   - 室主任或接口工程师：点击 **指派任务** 分配责任人；任务完成后点击方框审查确认
   - 所领导或管理员：查看汇总、审查任务或导出结果
6. 在 **写入任务记录** 中确认操作结果；若出现“Registry补偿”，程序会自动重试状态同步，不会重复写Excel
7. 再次点击 **开始处理** 或等待下一次刷新；任务完成后会退出设计人员待办，上级审查后会退出上级列表

常用操作顺序：**刷新文件列表 → 开始处理 → 完成/指派/审查 → 导出结果**。

### 1.2 账户登录与管理

首次使用时选择您的账户并输入密码，默认密码为 `password`。点击右上角 **⚙**，再点击 **账户管理** 可以：

- 输入目标账户密码后切换用户
- 输入当前密码后修改自己的密码
- 姓名用于识别角色和筛选负责的任务

### 1.3 界面布局

程序主界面分为以下区域：

- **顶部**：文件夹路径设置、导出位置设置、设置按钮、帮助按钮
- **中部**：Excel 文件信息显示区、项目号筛选复选框、写入任务记录面板
- **主体**：7 个选项卡，分别对应 7 种接口类型
- **底部**：功能按钮区、数据库状态显示、版本信息

### 1.4 设置文件夹路径

1. 点击 **浏览** 按钮选择包含接口 Excel 文件的文件夹
2. 默认路径为服务器共享文件夹
3. 点击 **刷新文件列表** 加载文件信息

### 1.5 7 种接口类型

| 选项卡 | 接口类型 | 说明 |
|--------|----------|------|
| Tab 1 | 内部需打开接口 | 需要打开的内部接口任务 |
| Tab 2 | 内部需回复接口 | 需要回复的内部接口任务 |
| Tab 3 | 外部需打开接口 | 需要打开的外部接口任务 |
| Tab 4 | 外部需回复接口 | 需要回复的外部接口任务 |
| Tab 5 | 三维提资接口 | 三维模型相关的接口任务 |
| Tab 6 | 收发文函 | 收发文函记录 |
| Tab 7 | FU | FU计划任务 |

### 1.6 数据库状态

左下角显示数据库连接状态：

- ✅ **已连接**：数据库正常工作
- 🔄 **同步中**：正在上传/下载数据
- ⏳ **等待锁定**：等待其他用户释放数据库
- ⚠️ **未配置**：尚未设置数据文件夹
- ❌ **连接失败**：请检查网络或联系管理员

### 1.7 开机自启动

在设置中可以启用或关闭 **开机自启动**。

### 1.8 写入任务面板

界面中部的写入任务记录面板显示所有后台写入操作的状态：

- 指派任务、回文单号写入、FU完成和Registry补偿等操作会显示在此面板
- 可以查看任务执行状态（排队中/执行中/已完成/失败）
- Excel写入成功但Registry暂时不可用时，会生成“Registry补偿”任务；该任务只重试状态同步，不会重复写Excel
- 支持按"只看我的任务"筛选
- 任务失败时会显示“失败”状态，可打开监控查看相关日志

### 1.9 帮助文档

点击主界面右上角的 **❓** 按钮打开帮助窗口，根据您的角色自动定位到对应章节。

## 2. 设计人员使用指南

设计人员是程序的主要使用者，负责查看和处理分配给自己的接口任务。

### 2.1 查看我的待办任务

1. 确保已在设置中填写正确的姓名
2. 点击 **刷新文件列表** 或 **开始处理**
3. 程序会自动筛选出"责任人"为您姓名的任务
4. 在各选项卡中查看分配给您的任务

### 2.2 任务列表说明

任务列表显示以下关键信息：

- **接口编号**：任务的唯一标识
- **接口描述**：任务的具体内容
- **接口时间**：任务截止日期
- **责任人**：任务负责人（即您的姓名）
- **科室**：所属科室
- **状态**：任务当前状态

**颜色标识**：

- 红色行：已延期任务（需优先处理）
- 普通行：正常进行中的任务

### 2.3 填写回复编号

当您完成某个接口任务后，需要填写回复编号：

1. 在任务列表中找到已完成的任务
2. **双击接口编号**
3. 在弹出的对话框中输入 **回复编号**
4. 点击确认保存
5. 写入操作会在后台异步执行，可在写入任务面板查看进度

批量填写时，按住 Ctrl 或 Shift 选择多个接口，点击选项卡右上角 **批量填写回文**。可以将同一回文单号应用到多个接口，也可以从Excel粘贴“接口号 + 回文单号”两列；仅粘贴一列时，数量必须与预览中的启用项完全一致。确认提交前请在预览中核对接口号与回文单号的对应关系。

**回文单号填写要求**：

- 请按照项目业务规定填写，程序不强制限定格式
- 提交前请仔细核对；程序不会覆盖已经写入的回文单号

### 2.4 完成FU任务

1. 在 FU 选项卡中找到本人负责的任务
2. 点击该行 **是否已完成** 方框；也可以双击内部编码
3. 程序在后台将当天日期写入原表D列
4. 写入成功后任务进入待审查状态

需要同时完成多个FU时，先多选任务，再点击选项卡右上角 **批量标记完成**，核对统一完成日期后提交。

### 2.5 导出我的任务

1. 设置好 **导出结果位置**
2. 勾选需要导出的选项卡
3. 点击 **导出结果** 按钮
4. 导出的 Excel 文件将保存到指定位置

### 2.6 注意事项

- 请定期刷新任务列表，确保查看最新分配
- 延期任务会始终显示，请优先处理
- 如发现任务分配有误，请联系室主任

## 3. 室主任使用指南

室主任负责管理本室的任务分配和进度监控。

### 3.1 任务分配功能

室主任可以将未分配的任务指派给设计人员：

1. 点击主界面底部的 **指派任务**
2. 在指派窗口中勾选需要处理的任务
3. 从下拉列表中选择设计人员姓名
4. 可将同一人员批量应用到多个勾选项
5. 点击确认保存

**批量分配**：

- 可以选择多行任务后一次性分配
- 使用 Ctrl+点击 选择多个任务
- 指派操作通过后台队列异步执行

**指派记忆**：

- 程序会记住上次对同一接口的指派人
- 下次处理时，未指派的任务会自动沿用上次的指派人

### 3.2 任务监控

室主任可以查看本室所有任务的进度：

- 任务列表自动按科室筛选（如一室主任只看结构一室的任务）
- 可以查看每个设计人员的任务完成情况

### 3.3 显示时间范围

室主任角色默认显示：

- **所有已延期任务**（无时间限制）
- **未来 7 个工作日内到期的任务**

此时间范围可在配置文件中调整。

### 3.4 确认回复

当设计人员填写回复编号后，室主任可以进行确认：

1. 查看已填写回复编号的任务
2. 核实回复内容正确
3. 点击勾选框完成审查确认；尚未完成的任务不能直接确认

### 3.5 忽略延期任务

对于不需要关注的延期任务，室主任可以批量忽略：

1. 点击 **忽略延期** 按钮
2. 在弹出的对话框中勾选需要忽略的任务
3. 输入忽略原因（可选预设或自定义）
4. 确认忽略

被忽略的任务不再显示、不在导出结果中。若接口时间变化，忽略会自动取消。

### 3.6 导出本室报表

1. 设置导出位置
2. 勾选需要导出的接口类型
3. 点击导出，生成本室的任务汇总表

## 4. 所领导使用指南

所领导可以查看全所的任务概况和紧急事项。

### 4.1 全局概览

所领导角色不按科室筛选，可以查看所有科室的任务。

### 4.2 显示时间范围

所领导角色默认显示：

- **所有已延期任务**（需要紧急关注）
- **未来 2 个工作日内到期的任务**

这意味着所领导看到的都是最紧急的事项。

### 4.3 报表导出

所领导可以导出全所的任务汇总报表：

- 包含所有科室的任务
- 按时间范围筛选后的数据

### 4.4 注意事项

- 所领导显示的是最紧急的任务，便于快速决策
- 如需查看更多历史任务，请联系管理员调整配置

## 5. 管理员使用指南

管理员负责系统配置和维护工作。

### 5.1 角色管理

角色信息存储在 `excel_bin/姓名角色表.xlsx` 中：

| 列 | 说明 |
|----|------|
| A列：姓名 | 用户的真实姓名 |
| B列：角色 | 用户角色（可多角色，用顿号分隔） |
| C列：密码 | 账户密码，默认值为 `password` |

用户切换时必须输入目标账户的密码。点击主界面右上角 **⚙**，再点击 **账户管理**，可切换账户或修改当前账户密码；修改结果会同步写入公共角色表。

**可用角色**：

- `设计人员`：普通设计人员
- `一室主任`、`二室主任`、`建筑总图室主任`：各室主任
- `所领导`：所级领导
- `管理员`：系统管理员
- `XXXX接口工程师`：项目接口工程师（如 2016接口工程师）

### 5.2 配置文件说明

**config.json** - 主配置文件：

```json
{
  "folder_path": "数据文件夹路径",
  "export_folder_path": "导出位置",
  "user_name": "当前用户姓名",
  "auto_startup": false,
  "minimize_to_tray": true,
  "defaults": {
    "folder_path": "默认服务器路径",
    "export_path": "默认导出路径"
  },
  "role_export_days": {
    "一室主任": 7,
    "二室主任": 7,
    "建筑总图室主任": 7,
    "所领导": 2,
    "管理员": null,
    "设计人员": null
  }
}
```

**参数说明**：

- `role_export_days`：各角色的显示/导出时间范围（工作日）
  - `null` 表示无时间限制
  - 数字表示显示未来 N 个工作日内的任务

### 5.3 数据库维护

Registry 数据库位于数据文件夹下的 `.registry/registry.db`：

- 使用 SQLite 格式，支持多用户并发访问
- 网络盘自动禁用 WAL 模式，改用 DELETE 模式
- Excel写入成功但Registry同步失败时，程序通过独立补偿队列自动重试Registry
- 数据库会自动迁移更新

**维护模式**：

- 管理员可在设置中启用"维护模式"
- 维护模式下其他用户会被提示并退出，释放数据库占用
- 维护完成后关闭维护模式

**备份建议**：

- 定期备份 `.registry` 文件夹
- 备份前确保没有用户正在使用程序

### 5.4 日志查看

点击 **打开监控器** 按钮可以查看实时日志：

- 显示文件处理进度
- 显示错误和警告信息
- 便于问题排查

### 5.5 更新管理

程序支持自动更新：

- 启动时自动检查更新
- 在设置中可以手动检查更新
- 更新文件存放在服务器指定位置

### 5.6 调试工具

项目包含调试工具用于排查接口可见性问题：

- `debug_tools/visibility_cli.py` - 命令行调试工具
- `scripts/` 目录下有多个数据库检查和诊断脚本

## 6. 常见问题解答

### Q1: 文件被占用怎么办？

**解决方法**：

1. 弹窗会显示当前占用文件的用户名
2. 等待该用户关闭文件后重试
3. 如果是自己占用，请关闭已打开的 Excel 文件
4. 如果持续出现，请联系管理员

### Q2: 数据库连接失败怎么办？

**解决方法**：

1. 检查网络连接是否正常
2. 确认服务器文件夹是否可访问
3. 尝试重新点击"刷新文件列表"
4. 如果问题持续，请联系管理员

### Q3: 看不到分配给我的任务？

**解决方法**：

1. 确认右上角显示的当前账户与实际使用人一致
2. 确认您的角色已正确配置
3. 检查是否有项目号筛选被禁用
4. 联系室主任确认是否已分配任务

### Q4: 如何更新程序？

**解决方法**：

1. 点击设置按钮（⚙）
2. 点击"检查更新"按钮
3. 如果有新版本，按提示进行更新
4. 更新完成后程序会自动重启

### Q5: 回复编号填错了怎么办？

**解决方法**：

程序不会覆盖已填写的回文单号。请停止继续操作并联系管理员，在备份原文件后按业务流程更正。

### Q6: 导出的 Excel 文件在哪里？

**解决方法**：

1. 检查"导出结果位置"设置
2. 点击"打开文件夹"按钮直接打开导出目录
3. 导出文件名包含日期和项目号

### Q7: 程序启动很慢？

**解决方法**：

1. 首次启动可能较慢，请耐心等待
2. 检查网络连接速度
3. 程序会自动使用本地缓存加速后续操作
4. 联系管理员检查服务器状态

### Q8: 如何最小化到托盘？

**解决方法**：

1. 在设置中勾选"最小化到系统托盘"
2. 点击关闭按钮时，程序会最小化到托盘
3. 双击托盘图标可以恢复窗口
4. 右键托盘图标可以完全退出程序

### Q9: 写入任务显示失败？

**解决方法**：

1. 确认写入任务面板中显示失败的任务类型，打开监控查看相关日志
2. 常见原因：文件被占用、网络断开、数据库锁定
3. Registry同步失败会显示为“Registry补偿”，程序将自动重试且不会再次写入Excel
4. 如持续失败，联系管理员
